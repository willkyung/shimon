## 데이터셋 출처

- **PROSPIE 인체 열스트레스 데이터** (Loughborough University 공개 데이터셋)
- 실제 사람의 열 스트레스 상황에서 측정된 생리·환경·작업 조건 데이터
    - 참가자 40명, 실험 조건 9종류, 총 155개 trial
    - 기후챔버 환경에서 1분 간격으로 심부체온(직장 체온계)을 포함한 생리 지표를 실측
    - 참가자 안전을 위해 심부체온 39.5℃ 도달 시 실험을 강제 중단하도록 설계된, 윤리위 승인 하의 인체실험 데이터

## 주요 입력 변수

| 변수 | 원본 데이터 출처 |
| --- | --- |
| 체감온도 | 기온(Temp) + 습도(Humidity)로 산출 |
| 연령 | Age |
| 작업강도 | Treadmill Gradient(경사, %) |
| PPE 착용 여부 | Clothing (통기성/비통기성) |
| 연속 작업시간 | Time + Activity(work/rest) 상태로 산출 |

### 5개로 압축한 이유 — 후보였으나 제외한 변수

| 변수 | 제외 근거 |
| --- | --- |
| 작업강도(속도) | 실측 데이터에서 표준편차 0.43으로 사실상 상수(대부분 5.5~6.2km/h). 정보량이 없어 제외 |
| 직사광선 | 전체 155 trial 중 33개(21%)에만 존재, 그마저도 특정 2개 조건에 편중되어 체감온도와 교란(confounding). 실제 분석에서 방향이 뒤바뀌는 신뢰할 수 없는 결과가 나와 제외 |
| VO2peak, 체지방률 등 | 원본 데이터에는 있으나, 실제 서비스에서 사용자가 입력할 수 없는 값이라 애초에 후보에서 제외 |

### 사용자 입력 → 모델 입력 매핑

사용자는 원본 수치(경사 %)를 직접 입력하지 않고, 앱의 "작업강도: 낮음/중간/높음" 3단계 선택지를 그대로 사용한다. 서버에서 학습 데이터의 gradient 분포를 3등분(tertile)한 대표값으로 자동 변환한다.

| 사용자 선택 | 대표값(gradient) |
| --- | --- |
| 낮음 | 3 |
| 중간 | 5 |
| 높음 | 7 |

## 예측 Target

- **심부체온 (Core Body Temperature)**
- 이후 심부체온을 기준으로 `안전` / `주의` / `위험`으로 해석

### 경계값을 이렇게 정한 이유

**1) 출발점 — 확정된 의학적·산업보건 기준**

| 기준선 | 출처 | 의미 |
| --- | --- | --- |
| 37℃ | 임상 상식 | 정상 |
| 38℃ | WHO, OSHA | 예방적 조기경보선 — 의무 휴식·수분섭취 |
| 38.5℃ | 캘리포니아 CHSWC 정책문서 | 확장 모니터링 촉발 |
| 40℃ | 임상 진단 기준 | 열사병(의료 응급) |

**2) 국제 기준을 그대로 쓰지 않고 보정한 이유**

모델의 검증 오차(5-fold 교차검증 MAE 0.372℃)를 감안하지 않고 국제 기준(38.0℃)을 그대로 판정 경계로 쓰면, **실제로 심부체온 38℃를 넘었던 위험 사례의 37.1%를 "안전"으로 잘못 분류**하는 것으로 실제 데이터에서 확인됐다. 온열질환 예방 서비스에서는 위험을 놓치는 오류(false negative)가 과잉경고보다 훨씬 치명적이므로, 모델 오차만큼 경계값을 보수적으로 낮춰 적용했다.

**3) 실증 비교 결과**

| 경계값 | 실제 위험 사례 탐지율 | 놓친 비율 |
| --- | --- | --- |
| 38.0℃ (국제 기준 그대로) | 62.9% | 37.1% |
| **37.6℃ (오차만큼 보정)** | **95.1%** | **4.9%** |

**4) 최종 결정된 경계값**

| 등급 | 예측 심부체온 범위 | 근거 |
| --- | --- | --- |
| 안전 | < 37.6℃ | WHO 기준(38℃) − 모델 MAE(0.37℃) |
| 주의 | 37.6 ~ 38.4℃ |  |
| 위험 | ≥ 38.4℃ | CHSWC 확장 기준(38.5℃) 근접 |

이 등급은 법정 휴식 의무를 대체하지 않는다. 체감온도 기반 법정 기준(산업안전보건기준에 관한 규칙 제560조)은 이 모델과 독립적인 Rule Engine이 항상 우선 적용하며, AI 등급은 법정 기준 도달 이전 단계의 선제적 우선순위 판단으로만 사용한다.

## 전처리 방법

### 실제로 수행한 것

- **결측치 처리**: 원본 데이터의 결측값은 `9999`로 코딩되어 있어, 이를 NaN으로 변환 후 제거했다 (기온·습도 1.4%, 심부체온 0.4% 결측)
- **단위 통일**: 시각 데이터(`HH:MM:SS`)를 분 단위 정수로 변환해, 연속작업시간 계산에 사용할 수 있도록 통일했다
- **Train / Test 분리**: 3분할(Train/Validation/Test)이 아니라, **참가자(40명) 기준 5-fold Group Cross-Validation**을 사용했다. 동일 참가자의 데이터가 train/test에 동시에 들어가면 성능이 부풀려지는 데이터 누수 문제를 막기 위함이다

### 수행하지 않은 것 (참고)

원본 슬라이드 개요에 있었지만 이번 전처리 과정에서는 실제로 하지 않은 항목이다. PPT에는 넣지 않는 것을 권장한다.

- **이상치 제거 또는 범위 제한**: 별도의 이상치 제거(IQR, z-score 등)나 값 클리핑을 수행하지 않았다. 결측치 코드(9999) 제거만 진행했다
- **범주형 변수 Encoding**: PPE(작업복) 변수는 원본 데이터에서 이미 1(통기성)/2(비통기성)의 숫자 코드로 제공되어, 별도의 원-핫 인코딩 등을 수행하지 않고 그대로 사용했다

## 모델 및 검증 결과

| 항목 | 내용 |
| --- | --- |
| 모델 | XGBoost Regressor (나무 100개, 최대 깊이 3) |
| 검증 방법 | Participant 기준 5-fold Group Cross-Validation |
| 5-fold 평균 MAE | 0.372℃ (표준편차 0.012) |
| 5-fold 평균 RMSE | 0.454℃ (표준편차 0.017) |
| 최종 학습 데이터 | 12,420개 시점 (원본 17,264개 중 휴식구간 제외·결측 제거) |
| 변수 중요도(SHAP, 평균 절대값) | 연속작업시간 0.230 > 체감온도 0.103 > 작업강도 0.071 > PPE 0.065 > 연령 0.051 |

### 왜 XGBoost인가 — 다른 모델과 비교

동일한 5-fold Group CV 조건으로 선형회귀·랜덤포레스트와 비교했다.

| 모델 | MAE(℃) |
| --- | --- |
| 선형회귀 | 0.362 |
| 랜덤포레스트 | 0.366 |
| **XGBoost** | 0.370 |

세 모델의 성능 차이는 표준편차 범위 안에 있어 통계적으로 유의미하지 않다. **XGBoost를 채택한 근거는 성능 우위가 아니라 설명가능성(SHAP)이다.** 실제로 PPE(작업복) 변수는 단순 상관계수로는 거의 0에 가까웠지만, XGBoost로 다른 변수와 조합해서 보면 중요도 2위로 올라온다 — "연속작업시간이 길 때 PPE 효과가 커진다"는 상호작용을 트리 기반 모델만 자동으로 포착할 수 있기 때문이다.

## 한계 및 향후 계획

- **표본 크기**: 관측치는 12,420개이나 실질적인 독립 표본은 참가자 40명 수준(동일인 반복측정). 인체 생리학 실험 기준으로는 준수한 규모이나 ML 기준으로는 크지 않음
- **연령대 편향**: 참가자가 19~40세로 젊은 층에 편중. 실제 한국 옥외노동자(고령·이주노동자 비중 높음)와 인구 특성 차이 존재
- **실험실 vs 실제 현장**: 트레드밀 기반 부하(경사 0~14%)와 실제 건설 작업(자재운반, 삽질 등 간헐적 고강도 노동)의 부하 패턴이 다를 수 있음
- **체감온도 민감도**: 실험 설계상 온도-시간 조합효과가 뒤섞여 있어, 모델이 체감온도 단독 변화에 상대적으로 둔감함이 확인됨
- **연속작업시간 외삽 한계**: 학습 데이터의 연속작업시간 최댓값이 61분이라, 그보다 긴 작업(실제 현장의 장시간 근무)에 대해서는 모델 예측이 61분 시점 값으로 고정(saturate)된다. 61분을 초과하는 경우는 법정 Rule Engine이 우선 적용되도록 설계에 반영되어 있다
